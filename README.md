# Users' Guide
LATTE is a pipeline to **quantify locus-specific expression of transposable elements (TEs) in short read RNA-seq**. LATTE is <u>implemented in Bash only till now, and requires no installation</u>. However, other softwares that are part of the pipeline are required. Users could choose the available way to install.

# Getting Started
```sh
# Quantify TE expression in a sorted BAM file
LATTE -b <sorted.BAM> -g <TE.gff.by.RepeatMasker> 
# Quantify TE expression through a list of BAM files (generating TPM and ReadCount table)
LATTE -l <list.of.BAM.files> -g <TE.gff.by.RepeatMasker> 
```
[Important considerations](./README.md.md#general-usage):
* `-b` <b>BAM file must be sorted by coordinate.</b>
* `-l` <b>List of BAM files must be sorted, one per line without any space.</b>
* `-g` <b>GFF file must be generated by [RepeatMasker](https://www.repeatmasker.org/). </b>

## From the repository
LATTE could be obtained from github (https://github.com/PengjuZ/LATTE). Then download the required softwares as following, and add them to the `PATH` variable. After that, recalling by absolute path. 
* Required for TE quantification
  * samtools == 1.17, 1.24
  * bedtools == 2.31.1
* Optional for anomalous ERV detection
  * python == 3.11, 3.14
  * numpy == 2.1.40, 2.5.1
  * pandas == 2.2.2, 3.0.3
  * scikit-learn == 1.5.1, 1.9.0
```sh
# 1. Clone the repository
git clone https://github.com/PengjuZ/LATTE.git
cd LATTE                        # Change to the LATTE directory
find . -type f \( -name "LATTE" -o -name "*.sh" -o -name "*.py" \) -exec chmod +x {} \;  # Make LATTE executable
export PATH="$PWD/bin/:$PATH"   # Add LATTE to PATH

# 2. Install dependencies
# Recomend build a new conda environment for LATTE
conda create -n LATTE
# Activate the conda environment for LATTE
conda activate LATTE
# Required for TE quantification
conda install -c bioconda samtools==1.24 bedtools==2.31.1
# Optional for anomalous ERV detection
conda install -c conda-forge python==3.14 numpy==2.5.1 pandas==2.0.3 scikit-learn==1.9.0

# 3. Check the installation of LATTE and dependencies
LATTE -v
samtools --version
bedtools --version
```

# Test files
Three files `test/test.bam` & `test/test_List_of_BamFiles` & `test/testTE.gff` are provided within LATTE for testing its operation. Once LATTE and its dependences are in your `PATH` variable, you can execute it as follows. Normally, this process takes in seconds. By default, output files would be generated in the current directory.
```sh
# Quantify TE expression in a single BAM file
LATTE -b test/test.bam -g test/testTE.gff
# Quantify TE expression in a list of BAM files
LATTE -l test/test_List_of_BamFiles -g test/testTE.gff
```

# General usage
Once LATTE and its dependences are in your `PATH` variable, you can execute it as:
```sh
# Quantify TE expression in a single BAM file
LATTE -b <sorted.BAM> -g <TE.gff.by.RepeatMasker> 
# Or quantify TE expression in a list of BAM files
LATTE -l <list.of.BAM.files> -g <TE.gff.by.RepeatMasker> 
```
Important considerations:
* `-b` <b>BAM file must be sorted by coordinate </b> as follows:
    ```sh
    samtools sort -@ ${process_num} ${unsorted_bam} | samtools view -b - -o ${sorted_bam}
    ```
* `-l` <b>List of BAM files must be sorted, one per line without any space.</b> Example:
    ```
    test/test_1.bam
    test/test_2.bam
    test/test_3.bam
    ```
* `-g` Notably, our testing has been conducted solely with the <b>GFF file from [RepeatMasker</b>](https://www.repeatmasker.org/). 
    * We recommend to use the following parameters to generate the GFF annotation file:
    ```sh
    RepeatMasker -pa ${process_num} -species ${species} -no_is -nolow -norna -poly -html -gff -dir ${output_dir}
    ```
    * The TE annotation file `<TE.gff>` shall be formatted as follows：
    ```
    1       RepeatMasker    dispersed_repeat        1604    1768    35.8    +       .       ID=1;Target "Motif:L2c" 2993 3159
    1       RepeatMasker    dispersed_repeat        3973    4154    25.9    -       .       ID=2;Target "Motif:MIRb" 46 240
    1       RepeatMasker    dispersed_repeat        10184   10306   29.3    -       .       ID=3;Target "Motif:L1MC5" 7810 7936
    1       RepeatMasker    dispersed_repeat        11130   11365   30.1    -       .       ID=4;Target "Motif:MIRb" 23 260
    ```
* `-o` Output prefix. Default: working directory. (Otherwise, recommend to use absolute path.)
* `-h` Complete parameters:
    ```sh
    Usage: LATTE -h
          -b  <BAM file (sorted)>
          -l  <List of BAM files (absolute path required, one per line, no space), restricted by -b>
          -g  <TE annotation file (format as RepeatMasker.GFF)>
          -o  <Output prefix> (default: working directory)
          -t  <Multiple threads for List of BAM files, restricted by -b> (default: 1)
          -f  <Minimum overlap requirement> (default: 0.5)
          -p  <Maximum likelihood value for assignment> (default: 0.8)
          -m  <Maximum iterations of the outer cycle> (default: 10)
          -M  <Maximum iterations of the inner cycle> (default: 10)
          -e  <Abnormal ERV detection> (default: Flase)
          -v  <Show version information>
          -h  <Show this help message>
    ```

# Advanced features
### 1. Cleaning the TE annotation file (gff)
In order to clean the silent TEs. A TE database is constructed from the long reads of RNA-seq in several domestic animals. Based on this database, types of silent TE from GFF file would be discarded. Then returning another GFF file for quantification. 
Presently, this function `GFFfilter.sh` is limited to a selection of domestic animals, **specifically pigs, cattle, sheep, goats, and chickens**. For the other species, users could customize the TE annotation file to adjust the active TE subfamilies.
```sh
scripts/filterGFF.sh -s <species> -g <TE.gff>
```

### 2. Detecting anomalous expression of ERVs
LATTE also comes with a python script that detects the anomalous  expression of ERVs by `-e`. It statistics the ratio of each ERV between RNA-seq and genome. Based on DBSCAN, the ERVs with anomalous value are deemed as exogenous.
For the specific parameters, Euclidean distance is used as the metric for computation. And the eps set to `3`. Moreover, users could modify them in that python script file `scripts/abnormal_ERVs.py` to increase or decrease its sensitivity. Additionally, users could modify the textfile `ERVFamily` to detect the specific TE subfamilies.
```sh
LATTE -b <bam> -g <TE.gff> -e
```

### 3. Expected probability threshold
This parameter `-p` determines the assignment of a multi-mapping TE read indicated by its expected probability. Increasing this parameter yields more accurate assignments but extends processing time due to fewer multi-mapped reads being resolved per cycle.
```sh
LATTE -b <bam> -g <TE.gff> -p 0.8 
```

### 4. Minimum overlap requirement
Due to most TEs are predominantly active in fragment. Therefore, the default standard is relatively loose to prevent the loss of TE reads. Herein, Users have the flexibility to adjust the key parameters, overlapping rate `-f`, to manage the number of TE reads. This step ensures a balance between capturing a comprehensive representation of TE expression and maintaining the integrity of the TE reads.
```sh
# Reporting only those intersections where 50% of the read is overlapped by a TE.gff (default)
LATTE -b <bam> -g <TE.gff> -o <output> -f 0.5
# Reporting only those intersections where 100% of the read is overlapped by a TE.gff
LATTE -b <bam> -g <TE.gff> -o <output> -f 1
```
